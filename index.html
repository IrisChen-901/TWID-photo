    做法一：GitHub Pages（免費、網址長期有效，推薦）

    5. 等 1～10 分鐘，同一頁會出現網址，格式是 https://你的帳號.github.io/倉庫名稱/。把它傳到手機，用 Safari 或 Chrome 貼上就能開。

    怎麼看懂整個 HTML 檔

    1. 一個 HTML 檔裡有三種東西

    <head>　網頁的設定，不會直接顯示
    • <title>　分頁上的標題
    • <style>　外觀（CSS）：顏色、大小、位置
    <body>　畫面上看得到的東西（HTML）：標題、按鈕、輸入框
    <script>　功能（JavaScript）：按下按鈕後要做什麼、怎麼裁切、怎麼存檔

    這個檔案的順序是：先 <style>（外觀），再畫面（HTML），最後 <script>（功能）。

    2. 怎麼讀一行程式

    種類範例（都是這個檔案裡真的有的）怎麼讀
    HTML<button class="btn" type="button" id="rot">旋轉 90°</button>button 是按鈕；class 是外觀用的名牌；id 是功能用的名牌；中間的字就是畫面上看到的字。標籤一定成對：<button> 開始，</button> 結束。
    CSS.btn{ border-radius:6px; min-height:40px; }.btn 表示「所有 class 是 btn 的東西」，大括號裡每一行是「屬性:值;」。圓角 6px、最小高度 40px。
    JavaScript$('rot').addEventListener('click', function(){ ... });找出 id 是 rot 的東西，被點擊（click）時，執行大括號裡的動作。
    設定資料{ key: 'id2', w: 3.5, h: 4.5 }大括號是「一組資料」，每項是「名稱: 值」，用逗號隔開。中括號 [ ] 是「一排項目」。

    註解是寫給人看的說明，程式不會執行：CSS 和 JavaScript 用 /* 說明 */，HTML 用 <!-- 說明 -->。

    3. 三步追蹤法：想改某個東西，要去哪裡找？

    1. 改畫面上的字：搜尋那段字（例如「旋轉 90°」），找到的是 HTML。
    2. 改它的顏色、大小：看那一行的 class="btn"，搜尋 .btn，到 CSS 裡改。
    3. 改它按下去的行為：看 id="rot"，搜尋 'rot'，到 JavaScript 裡改。

    也就是說，class 把 HTML 和 CSS 連起來，id 把 HTML 和 JavaScript 連起來。

    4. 讀大檔案的小技巧

    • 搜尋：Ctrl + F（Mac ⌘ + F）。
    • 跳到指定行：VS Code 按 Ctrl + G（Mac ⌃ + G）。
    • 摺疊：VS Code 每段程式左邊有小箭頭可以收合；Ctrl + K 再按 Ctrl + 0 全部收合，Ctrl + K 再按 Ctrl + J 全部展開。先全部收合，只展開要看的段落，就不會被淹沒。
    • 電腦版瀏覽器可以按 F12（或在畫面上按右鍵選「檢查」），再用左上角的「選取元素」點畫面上的東西，右邊就會顯示它對應的 HTML 和 CSS。

      把這 6 行取代原本的 6 行：

      顏色碼是 # 加 6 個字元，常見顏色：綠 #12894a、藍 #1d6fe0、橘 #d9480f、紫 #7b3fc4。rgba(18,137,74,.14) 是同一個顏色的半透明版本，用在輔助線之間的淡色範圍帶，最後一個數字越大越濃。

      常見修改 2：調整或新增證件照規格

      找到 。每個規格是一個大括號區塊，名稱（例如 id2）是這個規格的代號。想改數字，直接改冒號後面的值；想新增，複製一整個區塊，改代號和內容，再貼在最後一個區塊後面（記得區塊之間有逗號）。規格清單會自動長出新的選項，不用再改別的地方。

      欄位意思
      name規格清單上顯示的名稱
      short下載檔名用的短名稱
      w、h成品的寬、高（cm）
      top頭頂線離照片上緣的距離（cm）
      hmin、hmid、hmax頭頂到下巴的最小、建議、最大長度（cm）。下巴的實線畫在 top + hmid，兩條虛線畫在 top + hmin 和 top + hmax
      cols、rows、gap4×6 紙上橫向幾張、縱向幾張、照片之間的間距（cm）
      orient紙張方向：'land' 橫式（15.24 × 10.16 cm）或 'port' 直式（10.16 × 15.24 cm）
      uses「適用」的文字，會顯示在規格清單和預覽下方
      spec2網頁標題旁的規格摘要
      rules預覽下方的提示清單，一條一行，用逗號隔開，文字放在引號裡
      srcs規格來源連結，t 是名稱、u 是網址
      eye、digital美簽專用（眼睛輔助線、DS-160 按鈕），一般規格不用寫
      排版要放得下：橫向 cols × w + (cols − 1) × gap 不能超過紙寬，縱向 rows × h + (rows − 1) × gap 不能超過紙高。橫式紙寬 15.24、紙高 10.16，直式相反（單位 cm）。超過的部分會被紙邊切掉。
      新增規格的範本（貼在最後一個區塊後面）：
        myspec: {
    key: 'myspec', name: '我的規格', short: '我的規格', w: 3.5, h: 4.5,
    top: 0.4, hmin: 3.2, hmid: 3.4, hmax: 3.6,
    cols: 4, rows: 2, gap: 0.2, orient: 'land',
    uses: '這裡寫用途',
    spec2: '頭頂至下巴 3.2–3.6 cm',
    rules: [
      '第一條提示',
      '第二條提示'
    ],
    srcs: [{ t: '來源名稱', u: 'https://example.com' }]
  },

      如果規格後來有變動（例如頭部範圍改了），只要改那個區塊的 hmin、hmid、hmax，以及 rules 裡的文字。

      常見修改 3：自訂裁切的預設值、常用尺寸上限

      找到 。CUSTOM_DEFAULT 是「自訂裁切」分頁一開始的尺寸和輔助線；lines 裡每一行是一條輔助線：axis 是 'h'（水平）或 'v'（垂直），at 是位置（cm），sty 是線型（'solid' 實線、'dash' 虛線、'dot' 點線），label 是標籤文字。MAX_SAVED 是常用尺寸最多可以存幾個。

      改壞了或沒反應怎麼辦
      • 畫面空白、按鈕沒反應：多半是少了逗號、引號或括號。用原本下載的檔案重來，每次改之前先另存一份備份。
      • 改了沒有變化：確認改的是「修改區」，存檔後在瀏覽器按重新整理（Ctrl + R 或 ⌘ + R）。
      • 只在深色模式下顏色不對：深色那一組的顏色也要改。
      • 規格最後仍以受理機關的最新公告為準，改完請再核對一次。
